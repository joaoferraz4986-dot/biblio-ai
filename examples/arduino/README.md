# Projetos Arduino

Estes diretórios são materiais auxiliares e **não são livros**. Eles são distribuídos junto do app para que um livro importado possa referenciá-los ou para que o leitor os abra separadamente.

- `01-led-button/`: projeto Wokwi executável e documentado passo a passo.
- `02-protoboard-power/`: SVGs didáticos limpos sobre nós, alimentação e caminho da corrente.
- `03-rc-analysis/`: netlist ngspice e explicação do comportamento analógico RC.

A validação é executada com:

```bash
npm run validate:arduino
```
